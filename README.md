# TicketDesk

A modern issue tracking application built with Next.js, MongoDB, and React.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Database:** MongoDB Atlas via Mongoose
- **Styling:** Tailwind CSS v4 + Custom CSS Design System
- **Icons:** Font Awesome

## Features

- Create, edit, and delete tickets
- Categorize tickets (Hardware, Software, Project)
- Priority levels (1–5) with visual indicators
- Progress tracking with percentage slider
- Status management (Not Started, In Progress, Done)
- Responsive dashboard with category grouping
